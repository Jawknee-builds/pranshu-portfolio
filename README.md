---

## ✨ Highlights
- **Performance First**: Optimized Lighthouse score (95+) using static asset preloading and minimal client-side hydration.
- **Responsive Layout**: Designed mobile-first with adaptive typography and flexible grid systems.
- **Component Architecture**: Atomic, reusable UI primitives built on Radix UI conventions and Tailwind CSS.
- **Dark/Light Theming**: Accessible contrast ratios compliant with WCAG 2.1 AA.
